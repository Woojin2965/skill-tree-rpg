# Problem bank sources

Every type below is a template in `scripts/generate_seed.py` (same type ids): the numbers are drawn at random and SymPy computes the answer.
The exercise sets of the open textbooks below were read to decide which **types** of problem each skill needs.
No textbook problem is copied; only the kind of exercise is followed.

## Written for this app

These follow no textbook section. They exist so every skill has grade A and S problems for its promotion tests.

| Type | Skills |
|---|---|
| A.arith-linear | arithmetic, linear equations |
| S.arith-func-linear | arithmetic, functions, linear equations |
| S.seq-explog-func | sequences, exponents and logs, functions |
| S.trig-quad-func | trigonometry, quadratic equations, functions |

The first templates in `generate_seed.py` (expanding, factoring and differentiating expressions, and their composites) are also original.
